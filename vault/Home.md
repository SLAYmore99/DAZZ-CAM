# Home

## Projects
- [[FUN CAM]]: a free, open-source Android retro film camera inspired by the iPhone-only app
  Dazz Cam. Repo `slaymore99/dazz-cam`, branch `claude/clever-dijkstra-ij8cnl`. Since v0.4 it ships as four apps: DOT, GLASS, FIELD and Classic.

## Preferences / context
- The user has always used Android and wanted a Dazz Cam-style app on it.
- Cloud sessions can't reach the local vault, so notes are kept in the repo's `vault/` folder
  and synced locally at the end of a session.
- Tools in use: Claude Code (cloud) with a GitHub repo, and the REA (Reverse Engineer
  Anything) MCP, which can be set up with `npx rea-agents setup`.
