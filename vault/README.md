# Vault notes (to sync into the local Obsidian vault)

These notes mirror the user's local Obsidian memory vault
("VAULT FOR CLAUDE MEMORY"). Cloud sessions can't reach that vault, so Claude keeps them here.
At the end of a session, copy them into the local vault:

- `Home.md` → merge into the vault's `Home.md`. Add the link under Projects.
- `Projects/FUN CAM.md` → the vault's `Projects/` folder.
- `Sessions/*.md` → the vault's `Sessions/` folder, or wherever session logs go.
