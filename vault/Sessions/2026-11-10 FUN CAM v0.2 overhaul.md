# 2026-11-10: FUN CAM v0.2 overhaul

- The user shared real FUN CAM photos showing vertical line artefacts, blocky ghost edges and
  blown-out glow. They asked for proper research into each Dazz camera, more fun video cams,
  and a decluttered UI.
- **Research done:** see [[FUN CAM]] → "v0.2 overhaul". Dazz's source code is closed and not on
  GitHub. Open-source references studied: FilmCamera-Android (MIT), RetroCam, film-filters.
- **Built:** the render engine v2, 30 film/custom LUTs, 42 cameras, the new Dazz-style UI,
  and the web/iPhone port kept in sync.
- **The user can help by** sending Dazz reference photos per camera (ideally the same scene
  shot with the iPhone camera and with Dazz) so the looks can be tuned to match.
- **Open:**
  - device testing of v0.2
  - hosting the iPhone web app (the repo is private)
  - landscape Kino
