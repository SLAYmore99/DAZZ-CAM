# FUN CAM: context for new sessions

FUN CAM is a free, open-source (MIT) Android retro film camera, inspired by the iPhone-only
app Dazz Cam. It also has an iPhone version (a Safari web app and a Capacitor IPA). The owner
has always used Android and wants it as close to the Dazz Cam *experience* as possible, using
original names, art and looks.

## Read first
- `vault/Projects/FUN CAM.md`: full history, decisions and open items (Obsidian notes; the
  user syncs `vault/` into their local vault at the end of a session).
- `docs/CAMERAS.md`: the 42-camera roster and the research behind it.
- `docs/MATCHING.md`: how to match looks from iPhone-vs-Dazz photo pairs.
- `README.md`, `web/README.md`, `ios-app/README.md`.

## Architecture (short)
- **Android:** Kotlin, Compose and CameraX; the GLES3 pipeline is in `app/src/main/java/com/funcam/app/gl/`.
  - `Shaders.kt`: INPUT, then GRADE (3D LUT), DOWN, BLUR, COMPOSITE
  - `FilmPipeline.kt`, `FilmRenderer.kt` (live preview), `StillProcessor.kt` (full-res stills)
- **Cameras:** `model/Cameras.kt` (42 recipes). Per-camera user tweaks: `Tweak` in `model/Recipe.kt`.
- **LUTs:** `tools/make_luts.py` writes `app/src/main/assets/luts` and `web/luts`.
  - Film stocks are from the RawTherapee HaldCLUT pack (CC BY-SA 4.0); see `THIRD_PARTY.md`.
- **Web/iOS:** `web/` is a WebGL2 port.
  - `web/data.js` is GENERATED by `tools/gen_web_data.py` from Shaders.kt and Cameras.kt;
    re-run it after changing either. CI checks they stay in sync.
  - `ios-app/` wraps `web/` with Capacitor.
- **CI:** `.github/workflows/`:
  - `android.yml`: tests, lint, APK
  - `ios.yml`: unsigned IPA on macOS
  - `web.yml`: GitHub Pages
  - The APK and IPA are attached to the rolling `latest` release.

## User preferences / decisions
- Keep the current UI (camera wheel, Customize button, adjust chips); build on it, and don't
  revert it.
- Slow shutter must be available on every camera (photo and video), with a clear SLOW badge
  when it's on.
- Commit and push every change. Keep the `vault/` notes updated.
- Do NOT use, extract or study Dazz Cam's own files: no IPA assets, LUTs, frames or code.
  Improve the looks only by measuring photo pairs the user provides (`tools/match_look.py`).

## Build and test
```bash
./gradlew testDebugUnitTest lintDebug assembleRelease   # needs the Android SDK (platform 35)
python3 tools/gen_web_data.py                           # after shader/camera changes
python3 -m http.server -d web 8765                      # web app at http://localhost:8765
```
